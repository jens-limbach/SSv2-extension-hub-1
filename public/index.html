📜 Viewing Logs

You most likely deployed this app with the Cloud Foundry CLI (cf push). To watch what the microservice is doing — including the emoji-prefixed operational output — you only need one more command: 

# Live tail of the logs
cf logs crm-extension-hub

# Dump the most recent logs and exit
cf logs crm-extension-hub --recent

Replace crm-extension-hub with your app name from manifest.yml if you changed it. Log lines use ✅ info · 🔄 async started · ⏳ waiting · 📡 outbound call · ⚠️ warning · ❌ error.

One file does it all — see server.js. This dashboard is plain static HTML/CSS/JS served by the same Express app. No build step, no framework.
